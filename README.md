# Project-1-College-Recruitment-Improvement-Study
Goal: Using Python, perform an exploratory data analysis of the CCM Computing Courses Entry Surveys. Provide insights that can help the Information Technologies department increase enrollment in computing classes.

## Non Majors Survey Dataset Questions Focused on:
1. What are the main motivations for non-majors to enroll in a computing class at CCM?
2. Does prior exposure to CCM events or IT activities increase the likelihood of students wanting to take more computing classes?
3. Through which sources do students typically learn about CCM and its computing courses?
4. Which courses appeal most to non-major students?

## Project Files:
You can find 4 different project files in the GitHub Repository.
1. **Non-Majors_Survey_Results-Fall%202024.csv** is the CSV file of the Non-Majors Survey Results (before cleaning)
2. **nonmajors_survey_cleaned_survey_data.csv** is the CSV file of the Non-Majors Survey Results after cleaning
3. **Jismi Mathew - NonMajorSurveyProjectPt2.ipynb** is the Jupyter Notebook file that was used to explore the data and clean the data
4. **Jismi Mathew - NonMajorSurveyProjectPt3.ipynb** is the Jupyter Notebook file that was used to analyze the cleaned data to answer the 4 data science questions. It plots the data in an easy to read format and presents the findings from each graph and question.
